# タスクの〆切（Deadline）機能 仕様（v1）

> ステータス: 確定（grill-with-docs セッション 2026-07-21 合意済み）
> 用語の定義は [CONTEXT.md](../CONTEXT.md) を参照。

## 1. 背景・目的

「このタスクはいつまでにやる」という〆切を Task に持たせ、期限が近い・過ぎたことに気づけるようにしたい。
既存の Task は `title / completed / folderId` のみで、時間軸の情報を一切持たない。このギャップを Deadline で埋める。

## 2. 概念モデル

| 概念 | 説明 |
|---|---|
| **Deadline** | Task に設定できる任意の〆切。日付（時刻なし）で表す |
| **Overdue** | 未完了の Task が Deadline を過ぎた状態。保存状態でなく「今日 > Deadline かつ未完了」から導出される派生値 |

- Deadline は **Task のみが持つ**。Checklist / ChecklistItem は持たない。
- Overdue は Task の状態を増やさない。見た目の強調としてのみ表現される。

## 3. 機能要件

### 3.1 Deadline の設定・消去

| 操作 | 仕様 |
|---|---|
| 設定タイミング | **作成時・編集時の両方**で設定可能 |
| 消去 | いつでも未設定に戻せる（`null`） |
| 粒度 | **日付のみ**（`YYYY-MM-DD`）。時刻・タイムゾーンは持たない |
| 必須/任意 | **任意**。設定しない Task も存在できる |
| 過去日 | **許可**（バリデーションなし）。超過として表示される |

### 3.2 入力 UI

- **ネイティブの `<input type="date">`** を使用する。
- クイック入力ボタン（今日 / 明日 / 来週など）は v1 では作らない。

### 3.3 一覧表示

- **全タスク一覧・フォルダ内一覧の両方**に Deadline を表示する。
- 表示形式は**相対表示 + 絶対日付の併記**：
  - 未来・当日：`今日 (7/21)` / `明日 (7/22)` / `3日後 (7/24)` など
  - 超過：`2日超過 (7/19)` のように赤で強調
- **並び順は変更しない**（既存どおり作成日時 DESC）。

### 3.4 Overdue 判定

- **クライアント（ブラウザ）のローカル日付**を基準にする。
- Deadline は日付のみのため、`deadline < localToday` の文字列比較で判定する。
- サーバは日付の保存・返却のみを行い、タイムゾーンロジックを持たない。

### 3.5 完了済み Task の扱い

- 完了済みタスクは **Overdue 強調しない**（期限を過ぎていても赤表示しない）。
- Deadline の日付自体はそのまま表示する（消さない）。

### 3.6 データモデル・API（既存パターン準拠）

- DB: `tasks.deadline TEXT NULL`
- `CreateTaskInput.deadline?: string`
- `UpdateTaskInput.deadline?: string | null`
  - `undefined` = 変更なし / `null` = 消去 / `string` = 設定（`folderId` と同じ流儀）

### 3.7 v1 でやらないこと（YAGNI）

- 時刻・タイムゾーン
- Deadline 基準の並び順変更
- 「〆切あり」「期限超過」などのフィルタ
- クイック入力ボタン（今日 / 明日 / 来週）
- リマインダー・通知
- Checklist / ChecklistItem への〆切
