# モバイルでの完了タスク表示切替 仕様（v1）

> ステータス: 確定（grill-with-docs セッション 2026-08-10 合意済み）
> 用語の定義は [CONTEXT.md](../CONTEXT.md) を参照。

## 1. 背景・目的

「完了を表示」トグルボタンは `className="hidden md:inline-flex"` により、**md ブレイクポイント（768px）未満ではレンダリングされない**。このためスマホでは完了 Task を一切閲覧できない。

- 機能自体（`showCompleted` 状態と表示フィルタ）はモバイルでも動作する実装になっているが、UI の導線だけがデスクトップ専用になっている
- 導入時の issue（`issues/issue-202606272227.md`、status: DONE）に「モバイルでは非表示にする」という意図は記録されておらず、デスクトップのヘッダーに置いた結果として付いたクラスである → **バグ扱い**
- スマホでは「3/5 completed」というカウントだけが見えるのに実体にアクセスできず、全 Task 完了時には「All tasks completed.」と表示されるだけで復元手段がない

経緯の補足: 本トグルは 2026-06-27 の変更（bec3c8a）で、それまでヘッダーにあったモバイル専用フォルダ追加ボタンと**置き換わる形**で導入された。モバイルでの Folder 作成はその後ボトムシート（`FolderPickerSheet`、cd75adc）が担うため、本仕様の変更で失われる機能はない。

本仕様は、モバイルでも完了 Task の表示/非表示を切り替えられるようにする。

## 2. 概念モデル

| 概念 | 説明 |
|---|---|
| **完了タスク表示切替** | 現在の絞り込み（すべて / Folder / 未分類）を**変えずに**、その中に完了済み Task を含めるかを切り替える表示操作。Task の状態は変更しない。UI 表記は「完了を表示」「完了を隠す」 |

- 絞り込み条件（`FolderSelection`）とは**直交**する表示フィルタ。スコープを変えず、スコープ内の Task のうち完了済みのものを含めるかだけを変える
- 既定は**非表示**（未完了のみ表示）
- 表示状態は**セッション内のみ**保持し、リロードで非表示に戻る
- CONTEXT.md への用語追加は**しない**（Task の状態を変えない純粋な表示フィルタであり、ドメイン概念ではないため。既存の MarkAsRead はドメイン状態 LastRead を更新する操作である点で性質が異なる）

## 3. 適用範囲

- **モバイル**（`md` ブレイクポイント未満）へのトグル表示追加
- **デスクトップ**（`md` 以上）の現行挙動・見た目は変更しない
- モバイルのタスク行の窮屈さ（日付入力・移動先 select・削除ボタンの横並び）は対象外（`issues/issue-202607281142-mobile-task-row-layout.md` で管理）

## 4. 機能要件

### 4.1 トグルボタンの表示

| 項目 | 仕様 |
|---|---|
| 表示 | `md` 未満でもタスクカードのヘッダー右側に**常時表示**する。`hidden md:inline-flex` を外して `inline-flex` にする（Button のベースクラスが既に `inline-flex` のため、クラス削除のみでよい） |
| ラベル | 現行どおり「完了を表示」「完了を隠す」（デスクトップと同一。文言変更はしない） |
| 配置 | ヘッダー右側のボタン群の先頭（デスクトップと同じ位置） |
| 挙動 | タップで `showCompleted` を反転し、完了 Task の表示/非表示が即時反映される |
| 状態保持 | セッション内のみ。リロードで非表示に戻る（現行どおり） |

### 4.2 レイアウト

- 375px 幅で「選択タイトル（truncate 済み）+ N/M completed + 完了を表示ボタン」が**折り返しなしで収まる**こと
- タイトルの `truncate` は現行維持
- 完了 Task 表示中も `line-through` スタイルは維持する（現行どおり）

### 4.3 v1 でやらないこと（YAGNI）

- 表示状態の永続化（localStorage 保存。デスクトップ含め未実装のため今回も対象外）
- ラベル文言の変更（「完了を表示 / 完了を隠す」を維持）
- モバイルのタスク行レイアウト改善（別 issue）
- デスクトップのヘッダー・サイドバーの変更
- モバイルでの Folder 作成導線の追加・変更（ボトムシートの「新しいフォルダ」が既存の導線）

## 5. 検証方法

- 375px 幅（DevTools デバイスモード）で「完了を表示」ボタンが表示され、タップで完了 Task の表示/非表示が切り替わること
- 768px 以上で現行の見た目・挙動が変わらないこと
- `npm test` / `npm run typecheck` / `npm run lint` が緑であること
