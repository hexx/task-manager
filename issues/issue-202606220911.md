# 課題解決プロンプト: D1データベースによる永続化を実装する

## 1. 役割定義 (Persona)
あなたは高度なフルスタックエンジニアおよびCloudflare Workers/D1のエキスパートです。以下のコンテキストとゴールを基に、Task ManagerアプリにD1データベースによる永続化を実装してください。

## 2. 背景・前提条件 (Context)
- **現状のアプリ構成**: Task Managerアプリ（React 19 + Hono + Cloudflare Workers）
- **現状のデータストア**: インメモリ（`let folders: Folder[] = []; let tasks: Task[] = [];`）
- **問題**: サーバー再起動時にデータが消失する
- **関連ファイル**:
  - `src/server/store.ts` - データストア（インメモリ）
  - `src/server/app.ts` - APIエンドポイント
  - `src/shared/task.ts` - 型定義
  - `wrangler.toml` - Cloudflare Workers設定

## 3. 解決すべきゴール (Goal & Objective)
- [ ] Cloudflare D1データベースのバインディングを`wrangler.toml`に追加
- [ ] D1用のテーブル作成SQL（`folders`テーブル、`tasks`テーブル）を作成
- [ ] `src/server/store.ts`をD1クエリに書き換え
  - `listFolders()`, `createFolder()`, `updateFolder()`, `deleteFolder()`
  - `listTasks()`, `createTask()`, `updateTask()`, `deleteTask()`
- [ ] HonoのコンテキストからD1バインディングにアクセスできるようにする
- [ ] 既存のテストが全て通ること（テスト用にインメモリストアも残す場合は対応）
- [ ] TypeScriptの型エラーがないこと

## 4. 期待する成果物 (Output Format)
- 更新された`wrangler.toml`（D1バインディング追加）
- テーブル作成用のSQLファイル（`schema.sql`等）
- 更新された`src/server/store.ts`（D1クエリ実装）
- 更新された`src/server/app.ts`（D1バインディングの型定義）
- 動作確認結果（`npm run typecheck`）

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちに`wrangler.toml`へのD1バインディング追加から始めてください。
