# モバイルのタスク行が窮屈（日付入力・移動先・削除ボタンが横一列）

## 背景・前提条件 (Context)

### 期待される挙動 vs 実際の挙動
- **期待**: スマホ画面でタスク行の各操作（完了・〆切・移動先・削除）が無理なくタップできる。
- **実際**: タスク行に「〆切ラベル + 日付入力 + 移動先 select + 削除ボタン」が横一列に並び、狭い画面では `flex-wrap` で折り返されて見た目が崩れ、操作しにくい。

### エラーログ / スタックトレース
なし（機能は正常。見た目の整理・操作性の問題）。

### 再現手順
1. `npm run dev` でアプリを起動
2. スマホ幅（例: 375px）で DevTools のデバイスモードを開く
3. Tasks ビューで〆切付きのタスクを作成する
4. タスク行の右側が折り返され、日付入力・移動先・削除ボタンが窮屈に並ぶことを確認

### 環境情報
- 言語/ランタイム: Node.js、Vite + React
- 起動方法: `npm run dev`

### 関連ファイル / コード
- `src/client/main.tsx`（タスク行の描画部分）
```tsx
<li
  key={task.id}
  className="flex flex-wrap items-center justify-between gap-3 rounded-lg border p-3"
>
  {/* 左: チェックボックス + タイトル */}
  {/* 右: DeadlineLabel + <input type="date"> + 移動先 <select> + 削除ボタン が横一列 */}
</li>
```

### 試したが駄目だったこと
- なし（未着手）。なお移動先 select 自体はネイティブ部品のため、タップすると端末標準の選びやすい画面が開く。問題は行のレイアウト（窮屈さ）であり、select の部品選定ではない。

## 解決すべきゴール (Goal)
- [ ] スマホ幅でタスク行の操作が無理なくタップできるレイアウトに整理する（例: 二段構成にする、〆切編集を別導線にする等。方式は未定）
- [ ] デスクトップ幅の見た目を壊さないこと
- [ ] 既存のテスト・型チェック・lint を壊さないこと

### 完了条件（検証方法）
- 375px 幅で折り返しによる見た目の崩れがなく、各操作のタップ領域が確保されていること
- `npm test` / `npm run typecheck` / `npm run lint` が緑であること
