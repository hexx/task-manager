# 課題解決プロンプト: GitHub Actions CI の作成

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよびCI/CDパイプライン構築のエキスパートです。以下のコンテキストとゴールを基に、GitHub Actions を用いた継続的インテグレーション（CI）ワークフローを構築してください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: リポジトリに CI が一切設定されておらず、PR 作成時に自動テスト・型チェック・lint が実行されない。そのため、Renovate の依存関係更新 PR も CI ステータスが「no checks reported」となり、品質担保が自動化されていない。
- **プロジェクト構成**:
  - フレームワーク: React + Vite + TypeScript (フロントエンド)
  - バックエンド: Hono (Cloudflare Workers)
  - テスト: Vitest (ユニットテスト) / Playwright (E2Eテスト)
  - Lint: oxlint
  - 型チェック: `tsc --noEmit`
- **利用可能な npm スクリプト** (`package.json`):
  - `lint` → `oxlint`
  - `typecheck` → `tsc --noEmit`
  - `test` → `vitest run`
  - `build` → `vite build`
  - `test:e2e` → `playwright test`
- **関連ファイル/コード**:
  - `/workspace/package.json` — スクリプト定義と依存関係
  - `/workspace/.github/workflows/` — CIワークフローファイルの配置先（存在しない場合は新規作成）

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `.github/workflows/ci.yml` を作成し、push および PR 時に自動実行される CI パイプラインを構築する
- [ ] 以下のジョブを CI 上で実行すること:
  - `lint`: oxlint による静的解析
  - `typecheck`: TypeScript の型チェック (`tsc --noEmit`)
  - `test`: Vitest によるユニットテスト
  - `build`: Vite によるプロダクションビルド
- [ ] Node.js バージョンは `package.json` の `engines` フィールド（または `.nvmrc`）に準拠すること。未定義の場合は LTS 最新版 (v22) を使用する
- [ ] 可能であれば Renovate が自動生成する PR ブランチ (`renovate/*`) でも CI がトリガーされること
- [ ] 既存のプロジェクトコードやテストを変更しないこと

## 4. 期待する成果物 (Output Format)
- 作成された `.github/workflows/ci.yml` ファイル
- ワークフロー各ジョブの説明コメント
- CI ワークフローがトリガーされる条件（push / pull_request）の明示
- （オプション）ローカルでの動作確認用の `act` コマンド例

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちにプロジェクト構成の解析と `.github/workflows/ci.yml` の作成を開始してください。
