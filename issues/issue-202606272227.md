# 課題解決プロンプト: 完了タスクの非表示と表示切替ボタンの実装

## 1. 役割定義 (Persona)
あなたは React / TypeScript フロントエンドエンジニアであり、shadcn/ui コンポーネントライブラリを活用した UI 改善のエキスパートです。以下のコンテキストとゴールを基に、正確かつ効率的な実装を行ってください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: タスク一覧において、完了済みタスクも未完了タスクも常にすべて表示されている。完了タスクが増えるとリストが長くなり、アクティブな未完了タスクが見づらくなる。
- **現状の UI 挙動**:
  - タスク一覧は `src/client/main.tsx` の `App` コンポーネント内で `<ul>` に全タスクをレンダリング。
  - 完了済みタスクは `text-muted-foreground line-through` スタイルで視覚的に区別している。
  - ヘッダー部に `{completedCount}/{totalCount} completed` という進捗表示がある。
  - `Task` インターフェース（`src/shared/task.ts`）は `completed: boolean` プロパティを持つ。
- **関連ファイル/コード**:
  - `/workspace/src/client/main.tsx` — タスク一覧の表示ロジックと全体の UI コンポーネント
  - `/workspace/src/shared/task.ts` — `Task` 型定義
  - `/workspace/src/components/ui/button.tsx` — shadcn/ui Button コンポーネント
  - `/workspace/src/components/ui/checkbox.tsx` — shadcn/ui Checkbox コンポーネント

## 3. 解決すべきゴール (Goal & Objective)
- [ ] 完了済みタスク（`completed: true`）をデフォルトで非表示にする
- [ ] 完了済みタスクの表示/非表示を切り替えるトグルボタンを実装する
- [ ] トグルボタンには現在の表示状態に応じた適切なラベルを表示する（例: 「完了を表示」「完了を隠す」など）
- [ ] ボタンは `CardHeader` 内の進捗表示付近、またはタスク一覧上部の適切な場所に配置する
- [ ] 既存のタスク追加・編集・削除・チェックボックス切替の機能を壊さないこと
- [ ] 完了タスクが非表示の状態でタスクを完了（チェック）した場合、そのタスクは即座に非表示になること
- [ ] 完了タスクを表示した状態でも、既存の `line-through` スタイルは維持すること

## 4. 期待する成果物 (Output Format)
- 修正が完了した `src/client/main.tsx`（必要に応じて他ファイルも）
- 修正理由とアプローチの簡潔な解説
- 動作確認結果の報告
