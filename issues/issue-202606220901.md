# 課題解決プロンプト: Progressive Web App化する

## 1. 役割定義 (Persona)
あなたは高度なフロントエンドエンジニアおよびPWA実装のエキスパートです。以下のコンテキストとゴールを基に、Task ManagerアプリをPWA化してください。

## 2. 背景・前提条件 (Context)
- **現状のアプリ構成**: Task Managerアプリ（React 19 + Vite 8 + Hono + Cloudflare Workers）
- **現状のPWA状態**:
  - `public/manifest.json` は既に存在
  - `index.html` にPWAメタタグ（theme-color, apple-touch-icon, manifest link）は既に存在
  - **サービスワーカーは未実装**
- **関連ファイル**:
  - `public/manifest.json` - Web App Manifest
  - `public/icon.svg` - アプリアイコン
  - `index.html` - HTMLエントリポイント
  - `vite.config.ts` - Vite設定
  - `src/client/main.tsx` - アプリケーションコード

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `vite-plugin-pwa` を導入してサービスワーカーを自動生成
- [ ] オフラインキャッシュ戦略を設定（アプリシェル＋APIキャッシュ）
- [ ] manifest.jsonのアイコンをPNG形式も追加（SVGのみだと一部デバイスで非対応）
- [ ] インストールプロンプト（beforeinstallprompt）のハンドリングを実装
- [ ] オフライン時の動作を確認（アプリシェル表示、APIリクエストのハンドリング）
- [ ] 既存のテストが全て通ること
- [ ] TypeScriptの型エラーがないこと

## 4. 期待する成果物 (Output Format)
- `vite-plugin-pwa` の設定（`vite.config.ts`）
- サービスワーカーのキャッシュ戦略設定
- manifest.jsonの更新（アイコン追加）
- インストールボタンのUI実装（任意）
- 動作確認結果（`npm run typecheck`、`npm test`、`npm run build`）

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちに`vite-plugin-pwa`のインストールから始めてください。
