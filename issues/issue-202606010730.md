現在のタスク管理ツール（Vite + React構成）をPWAとしてホーム画面等に追加した際、アイコンがデフォルトの文字（Wなど）になってしまい、他のアプリと見分けがつきません。
一目でタスク管理アプリだと分かるように、以下の対応を一括で生成してください。

1. アイコン素材の作成
タスク管理ツールにふさわしい、シンプルで視認性の高いSVGアイコン（例: カラフルなチェックマークやクリップボードなど）のコードを出力してください。ファイル名は `public/icon.svg` とします。

2. index.html の更新
生成したSVGを favicon および Apple Touch Icon 等として読み込むための `<link>` タグを提示してください。

3. Web App Manifest の作成
PWAとしてインストールした際に、生成したアイコンが正しく適用されるように `public/manifest.json` を作成してください（すでに `vite-plugin-pwa` を使用している場合は、その設定内容でも構いません）。
