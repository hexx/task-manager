# 課題解決プロンプト: タスクのフォルダ移動UI実装（スマホ操作対応）

## 1. 役割定義 (Persona)
あなたは高度なフロントエンドエンジニアおよび React/TypeScript のエキスパートです。以下のコンテキストとゴールを基に、タスクを別のフォルダへ移動させる UI を実装してください。ただし、モバイル（スマホ）環境でも確実に操作できる UI を優先してください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: フォルダ機能自体は存在するが、ユーザーが「タスクを別のフォルダへ移動させる」操作 UI が未実装である。現在のタスク行には「完了チェックボックス」と「削除ボタン」のみがあり、フォルダ間での所属変更ができない。
- **バックエンドは移動可能な状態になっている（変更不要の見込み）**:
  - `PATCH /api/tasks/:id` は `folderId` の更新を受け付ける（`src/server/app.ts`）
  - `updateTask()` は `folderId` を変更可能（`src/server/store.ts`）
  - `taskApi.update(id, { folderId })` で呼び出し可能（`src/client/api.ts`）
  - 上記は既存調査済み。実装時は念のため動作を確認すること。
- **スマホ要件**: ユーザーは「スマホでも操作できるものが良い」と要望。そのためドラッグ＆ドロップ方式は非採用とし、**タップで操作できるセレクトボックス（ドロップダウン）方式**を採用すること。
- **プロジェクト構成**: React + Vite + TypeScript（フロントエンド）、Hono（Cloudflare Workers）。UI コンポーネントは shadcn 系（`@/components/ui/*`）。既に `md:hidden` 等でモバイル/デスクトップの表示切替（フォルダタブ・サイドバー）が実装されている。
- **関連ファイル/コード**:
  - `/workspace/src/client/main.tsx` — タスク行の `<li>` 描画と状態管理の中心。セレクトボックスを追加する箇所。
  - `/workspace/src/client/api.ts` — `taskApi.update(id, input)` が移動に利用可能。
  - `/workspace/src/shared/task.ts` — `Task.folderId`、`UpdateTaskInput.folderId` の型定義。
  - `/workspace/src/server/app.ts` / `/workspace/src/server/store.ts` — 移動用 API/ストア（確認用・変更不要の想定）。

## 3. 解決すべきゴール (Goal & Objective)
- [ ] 各タスク行に「移動先フォルダ」を選ぶセレクトボックス（`<select>`）を追加する。選択肢は「未分類（folderId = null）」＋ 取得済みのフォルダ一覧。
- [ ] セレクトボックスの変更時 (`onChange`) に `taskApi.update(task.id, { folderId })` を呼び出し、タスクの所属フォルダを更新する。
- [ ] 更新後は `loadTasks()` 等でリストを再読み込みし、UI の表示（選択中フォルダで絞り込んでいる場合の出し分け）を正しく反映させる。
- [ ] デスクトップ（サイドバー表示時）とモバイル（`md:hidden` のタブ/リスト表示時）の**両方**で、セレクトボックスをタップ操作だけで利用できるようにする（ドラッグ＆ドロップは使用しない）。
- [ ] セレクトボックスのスタイルは既存の shadcn UI トークン（`muted`, `border` 等）に合わせ、既存のチェックボックス・削除ボタンとのレイアウトを崩さないこと。
- [ ] 既存のユニットテスト（Vitest）および E2E テスト（Playwright, `/workspace/tests`）を壊さないこと。セレクトボックス追加により既存テストのセレクタ/アサーションが影響を受ける場合は、適宜テストを更新または追加する（フォルダ移動の動作確認テストを含めることが望ましい）。
- [ ] バックエンド側に未対応箇所が見つかった場合のみ、最小限の修正を加えること（基本はフロントエンドのみ）。

## 4. 期待する成果物 (Output Format)
- 修正が完了した `src/client/main.tsx`（および必要に応じた型/テストの変更）一式
- フォルダ移動がタップ操作（セレクトボックス）で完了することを示す動作確認結果（Vitest / Playwright の実行ログ、または手動確認手順）
- 修正アプローチと、スマホ操作を考慮した UI 選定理由（セレクトボックス方式を採用した理由）の簡潔な解説
