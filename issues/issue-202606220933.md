zn# 課題解決プロンプト: スマホで見たときにフォルダとタスクの領域が横並びで見づらい

## 1. 役割定義 (Persona)
あなたは高度なフロントエンドエンジニアおよびレスポンシブデザインのエキスパートです。以下のコンテキストとゴールを基に、モバイル対応のレイアウトを実装してください。

## 2. 背景・前提条件 (Context)
- **現状のアプリ構成**: Task Managerアプリ（React 19 + Tailwind CSS v4 + shadcn/ui）
- **現状の問題**: フォルダサイドバーとタスクリストが横並び（`flex`）で、スマホ画面では見づらい
- **関連ファイル**:
  - `src/client/main.tsx` - メインコンポーネント
  - `src/client/styles.css` - Tailwind CSS設定
- **現状のレイアウト**:
  ```tsx
  <div className="flex w-full max-w-3xl gap-4">
    {/* フォルダサイドバー: w-56 */}
    <Card className="w-56 shrink-0">...</Card>
    {/* タスクリスト: flex-1 */}
    <Card className="flex-1">...</Card>
  </div>
  ```

## 3. 解決すべきゴール (Goal & Objective)
- [ ] モバイル（〜768px）ではタブまたはドロップダウンでフォルダ選択に切り替え
- [ ] デスクトップ（768px〜）では従来通りのサイドバーレイアウトを維持
- [ ] フォルダの作成・削除機能がモバイルでも問題なく動作すること
- [ ] 既存のテストが全て通ること
- [ ] TypeScriptの型エラーがないこと

## 4. 期待する成果物 (Output Format)
- 更新された`src/client/main.tsx`（レスポンシブレイアウト）
- モバイルでのフォルダ選択UI（タブ、ドロップダウン、またはドロワー）
- 動作確認結果（`npm run typecheck`と`npm test`）

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちに現在のレイアウト構造の解析から始めてください。
