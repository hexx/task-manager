# 課題解決プロンプト: shadcn/ui で UIを再構成する

## 1. 役割定義 (Persona)
あなたは高度なフロントエンドエンジニアおよびReact UI実装のエキスパートです。以下のコンテキストとゴールを基に、shadcn/uiを用いたUI再構成を正確に行ってください。

## 2. 背景・前提条件 (Context)
- **現状のUI構成**: Task ManagerアプリがカスタムCSS（`src/client/styles.css`）で実装されている
- **使用フレームワーク**: React 19 + TypeScript + Vite 8
- **関連ファイル**:
  - `src/client/main.tsx` - メインコンポーネント（App）
  - `src/client/styles.css` - カスタムスタイル（約140行）
  - `src/client/api.ts` - APIクライアント
  - `package.json` - 依存関係定義
- **現在のUIコンポーネント**:
  - Card（タスクリストのコンテナ）
  - Input + Button（タスク追加フォーム）
  - Checkbox（タスク完了トグル）
  - Button（削除ボタン）
  - Alert/Message（エラー表示）

## 3. 解決すべきゴール (Goal & Objective)
- [ ] shadcn/uiの初期セットアップ（`npx shadcn@latest init`）
- [ ] 必要なコンポーネントをインストール（Card, Input, Button, Checkbox, Alert等）
- [ ] `src/client/main.tsx` のUIをshadcn/uiコンポーネントに置き換え
- [ ] `src/client/styles.css` のカスタムCSSを最小化（shadcn/uiのスタイルに統合）
- [ ] 既存の機能（タスク追加・完了トグル・削除）を壊さないこと
- [ ] TypeScriptの型エラーが発生しないこと

## 4. 期待する成果物 (Output Format)
- shadcn/uiで再構成された `src/client/main.tsx`
- 更新された `package.json`（shadcn/ui関連の依存関係追加）
- `components.json`（shadcn/ui設定ファイル）
- `src/components/ui/` ディレクトリ（shadcn/uiコンポーネント）
- 動作確認結果（`npm run dev` または `npm run typecheck`）

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちにshadcn/uiの初期セットアップから始めてください。
