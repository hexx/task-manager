# デスクトップのサイドバーのごみ箱に削除確認を付ける

## 背景・前提条件 (Context)

### 期待される挙動 vs 実際の挙動
- **期待**: デスクトップのサイドバーで Folder のごみ箱を押したとき、確認ダイアログが出てから削除される。
- **実際**: 確認なしで即座に削除される。誤クリックすると、Folder が消え、中のタスクはすべて「未分類」に移る（タスク自体は消えないが、分類が失われる）。

### エラーログ / スタックトレース
なし（仕様どおりの挙動だが、破壊的操作に確認がないことが問題）。

### 再現手順
1. `npm run dev` でアプリを起動
2. デスクトップ幅（`md` 以上）で開き、サイドバーの Folders に Folder を作成する
3. Folder 行にホバーしてごみ箱ボタンをクリックする
4. 確認なしで即座に削除されることを確認

### 環境情報
- 言語/ランタイム: Node.js、Vite + React
- 起動方法: `npm run dev`

### 関連ファイル / コード
- `src/client/main.tsx`（デスクトップ用サイドバーのごみ箱）
```tsx
<Button
  variant="ghost"
  size="icon-xs"
  className="opacity-0 group-hover:opacity-100"
  onClick={() => void removeFolder(folder.id)}
>
  <Trash2Icon />
</Button>
```
- 削除時のサーバー挙動（`src/server/store.ts`）: 該当 Folder のタスクは `folderId` が `null`（未分類）になるだけで、タスク自体は削除されない。

## 解決すべきゴール (Goal)
- [ ] デスクトップのサイドバーのごみ箱に確認ダイアログを挟む
- [ ] 確認文はモバイル版ボトムシートと統一する:
  - 中にタスクがある場合: `フォルダ『{名前}』を削除しますか？中のタスク{N}件は『未分類』になります。`
  - 空の場合: `フォルダ『{名前}』を削除しますか？`
  - ボタン: 「削除」（destructive）/「キャンセル」
- [ ] 既存のテスト・型チェック・lint を壊さないこと

### 完了条件（検証方法）
- デスクトップ幅でごみ箱クリック時に確認ダイアログが表示され、「キャンセル」で何も消えないこと
- `npm test` / `npm run typecheck` / `npm run lint` が緑であること
