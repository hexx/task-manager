# 課題解決プロンプト: TODOのフォルダ機能を実装する

## 1. 役割定義 (Persona)
あなたは高度なフルスタックエンジニアです。以下のコンテキストとゴールを基に、Task Managerアプリにフォルダ機能を実装してください。

## 2. 背景・前提条件 (Context)
- **現状のアプリ構成**: Task Managerアプリ（React 19 + Hono + Cloudflare Workers）
- **現状のデータモデル**:
  - `Task`: id, title, completed, createdAt, updatedAt
  - フォルダの概念は存在しない
- **関連ファイル**:
  - `src/shared/task.ts` - 型定義
  - `src/server/store.ts` - データストア（インメモリ）
  - `src/server/app.ts` - APIエンドポイント
  - `src/client/main.tsx` - UIコンポーネント（shadcn/ui使用）
  - `src/client/api.ts` - APIクライアント

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `Folder` 型を新規作成（id, name, createdAt, updatedAt）
- [ ] `Task` に `folderId` プロパティを追加（オプショナル、nullの場合は「未分類」）
- [ ] フォルダのCRUD APIエンドポイントを実装
  - `GET /api/folders` - フォルダ一覧取得
  - `POST /api/folders` - フォルダ作成
  - `PATCH /api/folders/:id` - フォルダ更新
  - `DELETE /api/folders/:id` - フォルダ削除
- [ ] タスク作成時にフォルダを指定可能にする
- [ ] フォルダでタスクをフィルタリング可能にする
- [ ] UIにフォルダのサイドバーまたはタブを追加
- [ ] 既存のテストが全て通ること
- [ ] TypeScriptの型エラーがないこと

## 4. 期待する成果物 (Output Format)
- 更新された型定義（`src/shared/task.ts`）
- 更新されたストア（`src/server/store.ts`）
- 更新されたAPIエンドポイント（`src/server/app.ts`）
- 更新されたAPIクライアント（`src/client/api.ts`）
- 更新されたUI（`src/client/main.tsx`）
- 新規テスト（フォルダ機能のテスト）
- 動作確認結果（`npm run typecheck` と `npm test`）

## 5. 実行開始の合図
